Agentes / Rol

Duelistas

Los duelistas están hechos para entrar primero, crear espacio y conseguir bajas. Si tu equipo necesita a alguien que abra sitio a la fuerza, este es el rol.

Agentes de este rol

  • Jett — movilidad vertical y de esquive; ideal para entradas rápidas y reposicionamiento.
  • Reyna — se cura y se vuelve invisible con bajas consecutivas; recompensa la agresividad.
  • Raze — explosivos de área para despejar rincones y rematar jugadas.
  • Phoenix — puede curarse a sí mismo y revivir en el punto donde cayó.
  • Neon — carga de energía para correr a gran velocidad y descargas eléctricas.
  • Yoru — portales y un clon señuelo para desorientar al rival antes de entrar.

Cómo jugar duelista

  1. Comunica cuándo vas a iniciar la jugada para que tu equipo pueda seguirte.
  2. Usa tu utilidad para negar líneas de visión antes de exponerte.
  3. Prioriza conseguir la primera baja; no fuerces si no tienes información.
  4. Después de abrir espacio, deja que el resto del equipo capitalice el hombre de ventaja.
